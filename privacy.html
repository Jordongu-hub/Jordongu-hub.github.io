Privacy Policy — 潮页上传 (Chaoye Uploader)

Last updated: October 15, 2026

潮页上传 is a personal tool operated by the owner of the YouTube channel "Tide & Pages Music". It is not offered to the public.

What the tool accesses

With the channel owner's permission, the tool uses the YouTube Data API to upload videos, set video metadata (titles, descriptions, tags, thumbnails, schedule) and manage playlists on the owner's own channel, and to read back that metadata to check it.

What we store

The OAuth token is stored only on the owner's own computer (macOS Keychain). No data from any other Google user is collected, stored, shared or sold.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See also the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
